# Customer Churn Analysis (EDA Project)

## Overview
This project explores customer churn in a subscription dataset, identifying key factors driving churn.  
The analysis focuses on tenure and engagement metrics to uncover actionable insights for improving retention.

## Key Insights
- New customers with low engagement are most likely to churn (~30%)
- Engagement impacts churn "more in early tenure" than for long-term users
- Business recommendations include onboarding campaigns, feature discovery, and early incentives

## Visualizations
- Heatmap showing churn rate by tenure bucket (rows) and engagement level (columns)
- Darker red indicates higher churn risk

## Tools & Techniques
- Python, pandas, seaborn, matplotlib
- Exploratory Data Analysis (EDA)
- Feature engineering (tenure and engagement buckets)
